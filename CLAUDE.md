# CLAUDE.md - Whizbang VSCode Extension

> **Quick Reference**: This is a **separate repository** from the main Whizbang library, providing VSCode IDE integration for Whizbang message-driven applications.

---

## Repository Overview

**Location**: `/Users/philcarbone/src/whizbang-vscode/`

**IMPORTANT**: Do not confuse this with `/Users/philcarbone/src/whizbang/tools/vscode-extension/` (different/older location in the main repo).

**Purpose**: Provides CodeLens annotations, hover tooltips, and navigation commands for Whizbang applications by reading the `.whizbang/message-registry.json` generated by the library's source generators.

## Key Features

### 1. Code Lens Annotations
Inline annotations showing message flow relationships:
- Dispatchers (who sends messages)
- Receptors (who handles commands)
- Perspectives (who observes events)

### 2. Hover Tooltips
Rich markdown tooltips with:
- Message classification
- Dispatcher/Receptor/Perspective locations
- Clickable navigation links

### 3. Navigation Commands
- `Whizbang: Go to Dispatcher`
- `Whizbang: Go to Receptor`
- `Whizbang: Go to Perspective`
- `Whizbang: Find Message Usages`
- `Whizbang: Show Flow Diagram`
- `Whizbang: Refresh Message Registry`

### 4. Message Registry Integration
Reads `.whizbang/message-registry.json` generated by Whizbang source generators at build time.

## Configuration

Extension settings (in `package.json`):

- `whizbang.enableCodeLens` - Enable/disable Code Lens annotations
- `whizbang.enableHoverInfo` - Enable/disable hover tooltips
- `whizbang.messageRegistryPath` - Path to registry JSON (default: `.whizbang/message-registry.json`)
- `whizbang.autoGenerateRegistry` - Auto-generate registry on build

## Troubleshooting

### Extension Not Activating
- Check that `.whizbang/message-registry.json` exists
- Verify activation events in `package.json`
- Check Output panel: "Whizbang" channel

### Code Lens Not Showing
- Verify message registry contains data
- Check C# file has message types (ICommand, IEvent)
- Rebuild project: `dotnet build`

### pnpm Issues
```bash
# Clear pnpm cache
pnpm store prune

# Reinstall dependencies
rm -rf node_modules pnpm-lock.yaml
pnpm install
```
